## Start the application {#start}

Open `CyTools_MeshStudio.exe` on Windows. If the private runtime is missing, follow the installation steps in [Features and installation](doc:guide-readme). Launchers and engine requirements differ by application; do not assume that a copied source folder is a portable installation.

## Engines and models {#models}

Each reconstruction, rigging or texturing backend has its own installation and hardware requirements. Installing one backend does not install all others. Models, engines and application updates are separate; gated weights require the user’s account and licence acceptance.

Read the licence and source shown for each component before downloading. When access is restricted, open the official model page, obtain access with your account and authenticate locally. Do not paste credentials into generation settings.

## Storage {#storage}

Keep application data and model weights separate from the application files. Check the selected installation folder and available disk space before starting a large download. Changing a download-cache setting does not move existing models.
