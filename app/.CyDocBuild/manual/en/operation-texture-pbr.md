Bake Base Color, Metallic, Roughness and Alpha into a UV atlas, plus the glTF packed metallic-roughness map. Colour carried by the mesh is baked; channels the mesh does not carry are derived with documented deterministic heuristics, not generated by a model.

## Parameters {#contract}

| Name | Type | Required | Description |
|---|---|---|---|
| `mesh_file` | `string` | Yes | Mesh path inside the configured mesh root: GLB, GLTF, OBJ, PLY, STL, OFF.  |
| `resolution` | `value` | No | Square size in texels of every generated map. `default=1024`, `enum=[512, 1024, 2048, 4096]` |
| `uv_mode` | `value` | No | auto keeps existing UV and unwraps only when there is none; keep fails without UV; unwrap rebuilds an atlas with xatlas and falls back to grid if xatlas fails; grid gives every triangle its own cell, which never overlaps but wastes texels. `default="auto"`, `enum=["auto", "keep", "unwrap", "grid"]` |
| `padding_pixels` | `integer` | No | Texels of nearest-neighbour padding grown around each UV island. `default=8`, `minimum=0`, `maximum=64` |
| `cavity_delight` | `number` | No | Brightens concave areas to attenuate shading baked into the source colour. Geometric heuristic, not an inverse-rendering de-lighting. `default=0.0`, `minimum=0`, `maximum=1` |
| `metallic_mode` | `value` | No | constant writes metallic_value; estimate applies the documented colour heuristic; source resamples the metallic-roughness texture of the mesh. `default="constant"`, `enum=["constant", "estimate", "source"]` |
| `metallic_value` | `number` | No | Constant metallic, and lower bound of the estimated metallic. `default=0.0`, `minimum=0`, `maximum=1` |
| `roughness_mode` | `value` | No | estimate applies the documented detail heuristic; constant writes roughness_value; source resamples the mesh metallic-roughness texture. `default="estimate"`, `enum=["estimate", "constant", "source"]` |
| `roughness_value` | `number` | No | Constant roughness, and centre of the estimated roughness. `default=0.5`, `minimum=0`, `maximum=1` |
| `alpha_mode` | `value` | No | from_source keeps the source transparency; opaque writes white; from_coverage marks the texels covered by a triangle, without padding. `default="from_source"`, `enum=["from_source", "opaque", "from_coverage"]` |
| `export_glb` | `boolean` | No | Also write a GLB carrying the UV layout and the generated PBR material. `default=true` |
